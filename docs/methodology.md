# Methodology

This repository preserves the original Earth Engine implementation used by SnowCloudMetrics.

## Metrics

- **SCF**: Snow Cover Fraction
- **SDD**: Snow Disappearance Date

## Data sources

- MODIS snow products for daily snow/cloud classification
- Auxiliary water masking layers to remove inland water bodies
- SRTM elevation for optional regional filtering in the app

## Notes

This documentation is intentionally brief and archival. It is meant to help readers
understand the legacy code, not to replace the scientific publication or the newer repository.
