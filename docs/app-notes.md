# App notes

The app UI script in this repository is a legacy Google Earth Engine interface that was used
to support the SnowCloudMetrics web experience.

## What it does

- sets up the map and drawing tools
- provides dropdowns and text inputs for geometry selection
- displays SCF and SDD layers
- adds legends and simple region summaries

## Important dependencies

- Earth Engine feature collections and image collections
- user-owned assets referenced in the script
- precomputed SCF and SDD image assets

## Historical note

This script is preserved as a reference implementation and may require asset path updates
if it is reused in a new environment.
